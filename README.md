# PixelBin error dashboard

Single-file dashboard (`index.html`) that renders GA4 failure events for PixelBin properties: per-property summary, paginated error rows, validation/internal error summary and category totals, over a rolling window.

**The embedded payload is synthetic.** The event taxonomy is real; every count, page path, organisation and error string is generated so no customer data is published. Earlier versions of this file were removed from history for the same reason.
